My Projects

AI Fake News Detection System

A machine learning based web application that identifies whether a given news article is REAL or FAKE.

Key Features

  • Accepts news text from users for analysis.
  • Classifies news as REAL or FAKE.
  • Uses TF-IDF for text feature extraction.
  • Uses Logistic Regression for prediction.
  • Trained using a local news dataset.
  • Flask backend connects the model with the website.
  • Displays the prediction result to the user.

Technologies: HTML, CSS, JavaScript, Python, Flask, Scikit-learn
